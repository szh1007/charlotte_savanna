# ADR-0006: 异步任务队列用进程内 asyncio 起步，预留分布式 MQ

- 状态: accepted
- 日期: 2026-08-18（自 README 选型 0006 拆出）
- 考虑过的方案: 直接上分布式 MQ——拒绝，引入 broker 运维成本，单实例 demo 阶段是过度设计；无抽象裸写 asyncio 队列——拒绝，无法演示「队列可替换」
- 后果: 进程内队列重启即丢；多实例部署时需替换为分布式 MQ（TaskQueue 抽象保证切换不改上层）

难点 #20「并发请求排队 + 长任务异步化」需要一个任务队列。P1 用进程内 asyncio 队列（FIFO + 并发状态锁），通过 `TaskQueue` 抽象预留分布式 MQ 切换。
