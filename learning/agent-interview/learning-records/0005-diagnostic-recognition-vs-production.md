# 首课诊断：识别 ≠ 产出，卡点集中在「需要外部概念组织回答」的题

首课自测结果（2026-10-10）：术语选择题与校准题**答对**（说明 `DESIGN #51` 的渐进披露、以及 Harness 这个词都是**认识**的），但三张口述卡（1 用 harness 开场说 CharAgent / 2 业务数字口径 / 4 上下文腐化用 2026 的词）**答不稳**。选择题里判断力题（怎么证明新版本更好）错了或犹豫。卡点自述为「想不起内容」。

**关键分辨**：答稳的两张卡（3 为什么手搓 / 5 演示路径）的答案**都在他自己的项目里**；没答稳的三张，答案**都在项目外面**（行业词、数字口径、术语链）。所以「想不起内容」的准确含义是 —— **想不起该调用哪些外部概念来组织回答**，不是想不起项目事实。

**Implications**：① 练习必须是**产出侧**（反查、口述、追问），选择题已证明能过；② 后续每份材料都要带「行业词 → 你的对应物 → 口述话术」三元组，纯知识陈述无效；③ 判断力题（口径意识）需要单独练 —— 这不是记忆问题，是答题策略问题。见 [[0003-gap-hypotheses-mostly-refuted]]、[[0004-fact-gaps-closed-remaining-work-is-retrieval]]。

**Evidence**：用户自报的口述卡 1/2/4 未答稳 + 选择题仅判断力题失分。
