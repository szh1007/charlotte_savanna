# Mission: AI Agent 岗面试（平台/基础设施 + 应用开发双轨）

> 面试导向。目标不是「学过」，而是**外部高频题打到你身上时，三层追问还能用自己的项目接住**。

## Why

2026-11 上旬前要面 AI Agent 相关岗位（Agent 平台/基础设施 + LLM 应用开发双轨）。当前的不对称：**项目侧极深，市场侧空白** —— 手写运行时有 1739 用例与 31 条 ADR，RAG 有两个真实子项目，但外面实际问什么、别人怎么答、哪些题自己的项目里根本没有对应物，一概不清楚。

面试里最贵的两种失败：**会却检索不出来**（知识在代码里，不在嘴上），和**盲区不知道是盲区**。

## Success looks like

- 手里有一份「外部高频题 → 我的项目实证」对照地图：每道高频题都能点名说清「用我哪个机制接」，而不是列出一堆「我不熟」
- **概念层已核实不缺**（见 `reference/existing-corpus-index.html` §4），所以成功标准是**能说出来**：自研运行时 / RAG / 评测三块，被追问三层仍在回答而不是转入防御
- 四条真缺口补齐：市场情报（外面在问什么）· 框架操作面事实（LangGraph 的 `interrupt` 到底怎么做）· 模型侧机制事实（不只是实测现象，还有机制解释）· 行业共同语言（轨迹/结果评估、基准名、五个 workflow 模式）
- 对比题不再卡壳 —— 例如「LangGraph 的 `interrupt` 和你的挂起-恢复有什么区别」「你为什么不用 LangChain」
- **「未做」项能讲成决策**：多智能体（`#42-44`）/ 无状态化（`#64`）/ 限流队列（`#20-22`）这些 ⬜ 项，答的是「核实后不做 + 判据 + 触发条件」，不是找补

## Constraints

- **1 个月内**（面试期约 2026-11 上旬）—— 紧凑模式：高频题全覆盖 + 关键难点动手练，不铺体系
- **求职期全职投入**（`.scratch/Charlotte/PLAN.md`：每天 16 小时，时间不是约束）—— 真正的稀缺资源不是工时，是「顺序」
- 教学工作区节奏约每周 6 小时（一课 + 一次动手练习）
- **目标岗位口径**：业务 Agent 落地（重业务链路 / 工具设计 / HITL / 评测），用 CharAgent 的运行时深度做差异化。投递面同时覆盖 Agent 平台/基础设施
- **判据沿用用户自己的两条**：① 面试官能看见什么 ② 会不会被问穿 —— 课程产出要能落到这两条上
- 面试形式含**共享桌面现场演示** —— 能被「跑起来」的东西优先于能被背诵的东西
- **教具就是自己的项目**：CharAgent / CharApp / rag_knowledge / rag_text2sql / charplot 的代码与 ADR 优先于抽象举例
- 存量底稿直接引用，不重写：`.scratch/CharApp/interview/`（5 份专题）、`.scratch/Charlotte/interview/`（3 份对话归档）
- 教学语言中文，技术术语保留英文原词
- 每课结尾留「被追问」环节：自己先答，agent 追问三层

## Out of scope

- 中间件（数据库 / 缓存 / MQ）—— 独立工作区 `learning/middleware/`
- 算法岗的微调 / 训练实操（概念对齐即可，不做实验）
- 前端与部署运维细节
- 背答案式刷题 —— 目标是压力下能检索并组织，不是复述
- 简历改写与投递策略（不是知识问题）
