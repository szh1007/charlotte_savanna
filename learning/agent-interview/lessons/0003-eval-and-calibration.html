Lesson 03 · 评测与口径

预判下一句追问

口径能力不是「报数字时加一句说明」，而是在面试官开口之前就知道他会追什么。 这一课把它练成一个可预测的动作 —— 而练的素材是你自己的真实数字。

2026-10-10 约 30 分钟 配套：话术底稿（新增 §2.4 四个易忘词的记忆钩子） Mission
为什么整课都放在评测上

三个互相独立的信号指向同一处：

  1. 首课的选择题里，判断力题（怎么证明新版本更好）是唯一失分的
  2. 第 2 课的四张失分卡里，两张是评测术语（pass@k / trajectory vs outcome）
  3. 第 2 课两道口径题选对了但有犹豫 —— 标准还没内化

而中文侧与英文侧两路调研是分开做的，却都判定：评测是市场区分度最高的一簇 （英文侧直接叫它 the differentiator）。 你最弱的地方，正好是市场最看重的地方 —— 这是这门课开到现在最该投入的一课。

1先花两分钟：四个词重测

上次没答上的四个词 —— 现在隔了一轮再测。能想起来说明进长期记忆了； 想不起来就再背一次 §2.4 的钩子，这个反复本身就是方法。

重测 · 「模型快满上下文时开始敷衍、急着收尾」叫什么？

Context Anxiety。因果链记法：rot 是机制 → anxiety 是症状 → reset 是处方。

重测 · 「子 agent 自行积累上下文、只回传结论」的机制名 + 两种模式名？

Context quarantine；模式是 isolate（默认）/ fork。quarantine = 检疫隔离，回来只带结论。

重测 · 「k 次机会里至少中一次」vs「k 次全都得中」，分别叫什么？你的跑批是哪一种？

pass@k（能力上限）vs pass^k（可靠性）。符号提示：@ = 至少一次，^ = 全都要中。

你每题跑 3 次取分布 → 走的是 pass^k 那一侧。

重测 · 「轨迹评估」和「结果评估」一句话怎么分？分工口径是什么？

轨迹答「怎么走的」，结果答「到没到」。分工口径：结果做回归门禁，轨迹做归因。

对应物：`judges.py` 的工具选择 / 参数正确率 = 轨迹；回答合规 / markdown 格式 = 结果。

2一条原则，解释你为什么会犹豫

原则面试官对你报出的数字的信任，属于哪一种？

  • 可累积的：报对几个就开始建立信任，越报越可信
  • 一次性的：发现一个数字是挑出来的，后面全部存疑
  • 看岗位的：技术岗对数字更宽容，产品岗更严格
  • 看类型的：性能数字严格，业务数字可以概略一些
对：一次性的。 这就是你犹豫的根源 —— 安全答法要求你主动放弃一个对自己有利的数字， 而这在面试压力下反直觉。想清楚这条原则，犹豫就没了： 你放弃的不是一个数字，是一个会被追穿的位置。

后两项之所以错，是因为它们都假设「存在一种可以宽松的场景」—— 不存在。 面试官不会因为岗位或数字类型改变核查方式，只会因为你已经把口径说了而跳过这一问。
由这条原则推出的动作

既然信任是一次性的，那正确策略不是「被问到时再解释」，而是预判并提前答掉。 也就是：每报一个数字，主动带三件套，让追问无处可落。

三件套回答什么防住哪句追问
被测对象在什么场景、什么问题类型上测的「所有情况都这样吗」
样本量几道题 / 几条轨迹「跑了几条」
重复次数跑几次、怎么处理离散「是不是挑的最好那次」

3训练：预判下一句追问

每题给一句你自己项目里的真实陈述。你要先说出：面试官下一句会追什么？ 然后展开对照。练的是预测能力 —— 预测准了，就能提前答掉。

预判 1 · 你说：「增量渲染把长答复的首字从 16.0s 降到了 1.4s。」

面试官下一句会追什么？你要提前补上哪两样？

会追：「所有问题都这样吗？」 —— 因为「长答复」这个限定一旦被忽略，数字就变成了对整个系统的承诺。

提前补上：场景限定 + 测量起止点。

你的成稿：「在长答复场景上，『答复区开始出字』这个时刻从 16.0s 压到 1.4s。 但要补一句边界：检索类题目首字差别很小 —— 那几秒都花在检索上，不在渲染上。 所以这个优化动的是答复生成到渲染这一段，不是整条链路。」

为什么主动说边界反而更强：它证明你测过、并且知道自己优化的是什么。 只说 16→1.4 的人，被问「检索题呢」时会卡住；主动说的人，直接把那问题关掉了。

预判 2 · 你说：「工具数量裁剪之后，token 降了 35~38%。」

这一条的追问你有现成答案，而且是反直觉的 —— 主动说出来

会追：「那钱降了多少？」

你的成稿（这条是你的强项，一定要主动说）： 「token 确实降了 35~38%，但钱几乎没变 —— 缓存让长前缀近乎免费。 所以裁剪真正省下的是窗口余量，不是账单。 另外工具选择的各项指标差异都落在臂内极差以内，也就是说这批题上没测出『工具越多越容易选错』。」

为什么这条特别值钱：行业普遍相信「工具越多越容易选错」，你有 A/B 数据说「这批题上没测出来」。 一个敢报阴性结果的候选人，比一个报涨幅的候选人可信得多。

预判 3 · 你说：「我做了两组 A/B 来验证改动。」

「A/B」这三个字本身会引出哪三个追问？

会追三连：多少题？跑几次？怎么判对错？—— 缺任何一个，「A/B」就只是个说法。

你的成稿：「题集是 20 题、6 个场景，每题场景一个 YAML 文件； 每题跑 3 次取分布；判对错用的是纯函数判据 —— 不碰网络、不碰库、不看时钟，同一份事实喂两次结论一定一样。」

提前答第三问的额外收益：一旦你说出「纯函数判据」，面试官立刻就有一个新问题 —— 见预判 6，先把答案准备好。

预判 4 · 你说：「期望零调用的题，我的准确率是 100%。」

这句话哪里危险？危险在哪一层 —— 数字本身，还是它的口径？

会追：「分母是什么？」—— 因为「100%」在评测里几乎总是口径问题，不是能力问题。

你的成稿（这条展示的是口径推导能力，同行少有）： 「准确率 = 实际 ∩ 期望 / 实际。期望集为空的题没有分母 —— 也就是『一个工具都没调』对纯咨询题是满分，所以这类题在汇总里单列『不适用』而不是按 0 分算。 同理召回率在期望集为空时也没有分母。两条指标分开池化：『名字选错了』和『名字对了参数传错』是两种修法。」

为什么这段话杀伤力大：大部分候选人报指标只有分子分母一句话。 能主动讲分母缺失怎么处理的人，说明他设计过判据而不只是用了判据。

预判 5 · 你说：「代付的恢复请求重放两次，一分钱没多扣、工具一次没多跑。」

这是个强结论。面试官会追什么？你的证据链有几环？

会追：「凭什么保证？少一环会怎样？」

你的成稿（三环，缺一不可）： ① 幂等键取三列 (run_id, message_id, tool_call_id) —— 上游每轮从 call_0 重新编号，少一列必撞； ② 键持久化在 PG，进程重启也拦得住； ③ 恢复时只补做欠着的调用，已完成轮次一步不重跑，没有人的结论就报错绝不自动执行。

预判的延伸：面试官很可能接着问「这和 HITL 的关系是什么」—— 答：一次工具调用的行状态就是审批单（needs_approval + approved_by/at）， 所以挂起不建审批表，没有两张表要同步。

预判 6 · 你说：「我的判据是纯函数，刻意不用 LLM-as-judge。」

这句话是主动亮出来的立场，所以一定会被反问。反问答不好会显得是回避

会追：「那语气、说服力、多轮策略这些你怎么评？」—— 这是这套判据真实的边界，回避就输了。

你的成稿（先给方法论坐标，再给边界，最后给判据）： 「LLM-as-judge 有三种已知偏差 —— 位置、长度、自我偏好，缓解手段是多 judge 交叉、交换候选顺序、结构化 rubric。 我刻意不用它，因为我要证的两件事都能规则化，而引 judge 会把非确定性引进判据本身 —— 那『这次比上次好』这句话就不再可复现了。 边界我也清楚：语气、说服力、多轮策略这类过程质量，我这套判据量不了。 真需要评那类质量时，才该上 judge，并且按上面三条偏差做缓解。」

为什么这样答不会被追穿：你先说出了对方的立场（三偏差 + 三缓解）， 再给出自己不用的理由，最后主动划边界。 顺序很重要 —— 先讲对方的优点再讲自己的取舍，听起来是判断；反过来听起来是偏见。

4把你摆进评测的坐标系

四组词，每组都是「一对容易混的概念」。被问到时，先说区分，再说你落在哪边。

一组词区分你落在哪边
trajectory
vs outcome		 怎么走的 vs 到没到 两条都有：工具选择 / 参数正确率是轨迹，回答合规 / markdown 是结果
pass@k
vs pass^k		 至少中一次 vs 全都得中（能力上限 vs 可靠性） pass^k 侧：每题跑 3 次取分布
capability
vs regression		 探能力边界 vs 防退化 两组 A/B 是 capability；同批题重跑是 regression
grader / trial / transcript 判分器 / 一次跑 / 完整记录（Anthropic 的标准词汇表） judges.py / 一次跑批 / 报告里的逐题表
一条要主动讲的边界（诚实 = 加分）

Anthropic 那篇给的标准词汇表里，harness 指「被测装置」—— 也就是模型 + 你这一整套工程一起被评。 你的离线评估也是这个口径：评的是「CharApp + 模型」这个整体，不是模型本身。 主动说这一句，等于告诉面试官你知道自己在测什么。

5被追问三层

三个问题，答完我出第 4 课

  1. 六个预判里，你有没有「预判得比参考答案更狠」的？ 如果有，说明你的直觉比这张表好，那就按你的说法改 —— 底稿要用你自己的句式才背得牢。
  2. 「数字乘以场景」这条心理阻力还在吗？ 具体感受一下：下次你说 16→1.4 的时候，会不会主动加上「但检索类题目差别很小」？ 会，说明原则内化了；还需要提醒，我就再做一组更狠的反例训练。
  3. 现在看「评测」这一簇，你觉得自己是稳 / 中 / 弱？ 你的实现是同行里强的一档，但这轮之前你答不出它的术语 —— 我想知道你现在怎么评估自己， 因为这个自我评估本身会影响你面试时的语气（心虚和笃定，面试官听得出来）。

另外：这一课的六段「成稿」我写的是可以照说的句子。哪段你觉得不像自己说话，指出来我重写。
