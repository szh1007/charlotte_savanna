# ADR-0001: 采用 yt-dlp 作为下载引擎

- 日期：2026-08-19
- 状态：已接受

## 背景

需求要求从大量平台下载视频，且明确「不要自己承担风险」。自行实现各平台解析与下载协议成本高、易被封禁、维护负担重。

## 决策

下载引擎直接采用开源项目 [yt-dlp](https://github.com/yt-dlp/yt-dlp)（Unlicense 公共领域许可，185k stars，活跃维护），通过其 Python API（`yt_dlp.YoutubeDL`）嵌入后端，不 fork、不修改引擎源码。

## 后果

- 支持约 2000 个站点，能力随上游持续更新
- 引擎升级 = `pip install -U yt-dlp`，零代码改动
- 领域边界同步继承：yt-dlp 不破解 DRM，本项目同样不提供任何绕过能力
- 依赖 ffmpeg（合并音视频流），部署环境需预装
- 下载失败原因以 yt-dlp 异常为准透传，不自行猜测
