# ADR-0003: 下载任务存内存态 + TTL 过期清理，不引入数据库

- 日期：2026-08-19
- 状态：已接受

## 背景

需求要求「先不需要数据库，尽量轻量」。下载任务与交付文件都是短生命周期资产，历史任务无持久价值。

## 决策

任务状态、队列、交付链接全部保存在进程内存中（`dict` + 线程安全锁）；交付文件落在 `downloads/` 目录，由后台清理任务按 TTL（免费 24h / 会员 72h）定期删除文件并标记任务 `expired`。服务重启后所有任务作废。

## 后果

- 无需数据库迁移、无 ORM、无连接池，依赖最少
- 缺点明确接受：单进程内状态、重启即失、不支持多实例横向扩展 —— 学习项目可接受
- 未来需要持久化时，将 `task_manager` 的存储层替换为 SQLite/Redis 即可，领域状态机不变
