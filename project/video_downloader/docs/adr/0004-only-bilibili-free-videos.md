# ADR-0004: 收缩为仅支持哔哩哔哩免费视频 (BilibiliDownloader)

- 日期：2026-08-20
- 状态：已接受

## 背景

原定位「全网/万能下载」(ADR-0001 宣称支持约 2000 个平台), 实际使用中大部分
平台需要 cookie 或加密验证, 处理成本高、维护负担重; 本项目为个人学习项目,
多平台支持超出学习范围。界面品牌与配色 (深色粉紫「万能下载站」) 需随范围
收缩同步调整。

## 决策

1. 产品改名 BilibiliDownloader, 中文副名「哔哩哔哩下载器」; 界面改浅色
   B 站粉蓝品牌主题 (主蓝 #00AEEC + 主粉 #FB7299)。
2. 仅支持哔哩哔哩免费公开视频 (非会员、非充电内容): URL 域名白名单校验
   (bilibili.com 主域及子域 + b23.tv 短链), resolve / downloads 路由共用,
   其余域名在引擎调用前拒绝 (422)。
3. 平台列表接口收窄为仅 B 站一项; total (引擎全量支持数) 保留在响应中,
   前端不再宣传。
4. 其他平台预留架构扩展点: 域名白名单与平台清单均为独立常量/结构, 未来
   扩展只需增补条目并放行对应域名。
5. 历史记录 (bugfix/0001-0007、ADR-0001、PRD) 保留原文不改, 本 ADR 覆盖
   ADR-0001 的适用范围。

## 后果

- 下载失败面收窄到哔哩哔哩单一平台, 错误处理与测试更聚焦
- 引擎内短链跳转 (b23.tv → bilibili.com) 不受域名校验影响 (只约束用户输入)
- 不做下载执行时二次域名校验: 请求入口统一校验 + 内存态任务无篡改面 (KISS)
- 未来扩展其他平台: 更新域名白名单 + 平台清单 + 界面文案即可
