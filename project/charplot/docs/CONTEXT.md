# CharPlot

AI 闯关学习网站：用户输入想学的知识（主题或材料），AI 自动获取知识并生成交互式问答闯关，通过游戏化机制让用户更轻松地学习任意知识。

定位（已确认，2026-08-21）：**自用学习项目，架构按真实产品设计** —— 账号体系、分享、部署等架构要素齐全；付费商业机制（连胜冻结卡、心动值充值等）一律降级为轻量化实现策略。

## Language

> 术语随审问会话逐步精炼，未决议的暂以用户原话记录。

**CharPlot**:
产品名称。AI 闯关学习网站的代号。
_Avoid_: 闯关学习, breakthrough_study(旧目录名)

**学习知识 (Knowledge)**:
用户想学的内容。输入形态：一句话、一段话、文档、视频、网页链接。
_Avoid_: 主题, 教程

**学习旅程 (Journey)**:
一次输入（主题/材料/知识库）产出的完整学习单元：知识图谱 + 关卡集。UI 上显示为「闯关地图」。
_Avoid_: 课程, 学习路径, course, path

**答题记录 (Attempt)**:
用户逐题的答题记录：题目、所选答案、对错、时长、时间戳。后台分析的原始数据源。
_Avoid_: 记录, 答题日志

**连胜 (Streak)**:
连续学习天数，习惯养成的核心钩子。
_Avoid_: 打卡, 连续天数

**经验值 (XP)**:
答题/通关获得的经验值，累积提升用户等级。
_Avoid_: 积分, 分数

**心动值 (Heart)**:
5 颗心，答错扣心，扣完该关需重开——「安全失败」压力机制。
_Avoid_: 生命值, 血量

**学习币 (Coin)**:
通关获得的货币，兑换连胜冻结等轻量化付费替代品。
_Avoid_: 金币, 奖励

**关卡 (Level)**:
AI 生成的交互式问答单元，通关所需时间按 3 分钟量级设计（借鉴 Duolingo 轻量化微学习）。
_Avoid_: 课, 单元

**题目 (Question)**:
关卡的最小组成单元，含题目文本、选项、正确答案与知识讲解（答错也展示讲解）。
_Avoid_: 题, 选择题

**通关 (Clear)**:
答完一个关卡的全部题目并获得"成功感"收尾的状态。
_Avoid_: 完成, 通过

**复盘报告 (Review Report)**:
通关后 AI 生成的知识总结，可分享给好友。
_Avoid_: 报告, 学习报告

**知识库 (Knowledge Base)**:
RAG 定制知识库，可配置、可选用作答题学习的知识来源。
_Avoid_: 语料库, 资料库

**知识获取管道 (Knowledge Pipeline)**:
统一的知识加工流程，不区分模式：输入归一化（解析）→ 主内容分析 → 网络搜索增强 → 知识解构。输入几句话 → 联网搜索获取知识；输入文档（docx/pptx/md/txt/html/pdf/网页链接）→ 先解析分析材料，**再联网搜索增强**。
_Avoid_: 主题模式, 材料模式, 检索模式

**章节 (Chapter)**:
知识图谱的第一层分组，学习主题下的大知识块，末尾可设 Boss 战。
_Avoid_: 单元, 模块, section

**知识点 (KnowledgePoint)**:
知识图谱的原子节点，关卡的粒度单位；带前置依赖边（prerequisite）构成有向图，是技能树与间隔复习的锚点。
_Avoid_: 技能节点, 知识节点, topic

## 决策记录

- 2026-08-21 Q1: 定位为"自用学习项目 + 完整产品架构"（A→B 偏向），非公开产品。付费机制轻量化替代。
- 2026-08-21 Q2: 知识获取采用**统一管道**（ADR-0002，非双模式）：所有输入形态先归一化解析，联网搜索作为标配增强环节（材料也要搜）。首版支持纯文本 / docx / pptx / markdown / txt / html / pdf / 网页链接。
- 2026-08-21 Q3: 视频输入首版不做，架构预留（入口归一化为转录文本，二期复用 video_downloader 转录能力）。
- 2026-08-21 Q4: 出题前先**解构成知识图谱**（章节 → 知识点 + 前置依赖边），关卡按知识点粒度生成。技能树 / Boss 战 / 间隔复习均锚定在图谱上。
- 2026-08-21 Q5: **图谱一次性解构 + 题目渐进生成**：学习开始时生成完整图谱（全貌地图可见），题目按关生成；间隔复习在生成新关时动态混入 20% 历史易错题；预生成缓解等待延迟。
- 2026-08-21 Q6: 首版题目类型 = 选择 + 判断 + 填空（规则判分）；代码题 / 对话式自由回答共用「LLM 评判」组件二期接入。关卡设计规范：3 分钟/关、由浅入深、简单题收尾（Duolingo 原则采纳）。
- 2026-08-21 Q7: 首版游戏化 = XP + 等级 + 连胜 + 心动值（5 心，答错扣心）；成就勋章与排行榜后置；连胜冻结卡降级为「学习币兑换」（每次通关获得学习币）。
- 2026-08-21 Q8: 知识正确性三层防护：①生成约束（题目/讲解只基于检索片段，附来源引用）②讲解区展示来源链接 ③「题目有问题」反馈标记计入后台分析。
- 2026-08-21 Q9: **双后端微服务**（ADR-0001）：Django = 账号体系 + 学习数据；FastAPI = AI 能力端（LangChain + LangGraph + DeepAgents 三件套）。前端 Vue 3。
- 2026-08-21 Q9b: **闯关交互归 Django**（ADR-0003，首版判分/反馈/游戏化是纯规则 + 预生成讲解，无 LLM 参与，数据就地完成）；**RAG 全链路归 FastAPI**（索引/检索/生成都是 AI 能力），Django 只存知识库元数据。Boss 战对话流式（二期，真 LLM 交互）入 FastAPI。
- 2026-08-21 Q10: 向量库直接 **Milvus**（menu 已验证部署），知识库 = Milvus collection + Django 元数据。
- 2026-08-21 Q11: 间隔复习 = **轻量规则调度**：知识点易错分（答错+2/答对-1，下限 0）+ 时间衰减（距上次复习越久越优先），新关生成时混入 Top 20% 易错点；无独立复习页，新关即复习载体。
- 2026-08-21 Q12: 复盘报告 = **公开只读链接页**（slug URL + OG 社交卡片，无登录可看）；私密分析报告站内展示。
- 2026-08-21 Q13: **知识点:关卡 = 模型支持 1:N，默认 1:1 生成**：关卡挂知识点 + 序号，技能树节点恒为知识点，大知识点生成时可拆 2-3 关（难度递进）。
- 2026-08-21 Q14: 生成任务编排 = **FastAPI 异步任务 + Redis 状态 + SSE 进度推送**，失败自动重试；预生成（学当前关时后台生成下一关）复用同一任务系统。
- 2026-08-21 Q15: 核心实体命名确认：**Journey / Chapter / KnowledgePoint / Level / Question / Attempt / KnowledgeBase / ReviewReport**，游戏化 = Streak / XP / Heart / Coin。
- 2026-08-21 Q16: 后台分析 = **自建 Dashboard**（Vue + Django API）：①掌握度矩阵 ②学习活动统计 ③易错点清单 ④LLM 文字版状态总结（FastAPI 出接口）。**另需全面的事实静态记录**：登录天数、连胜/最大连胜、已学章节、在学章节、已答/答对/答错数等——事实表全记录（Attempt + 用户事件），聚合按需计算，动态报告是事实数据的上层加工。
- 2026-08-21 Q17: 前端 = Vue 3 + Vite + **Element Plus 主题定制**（B 站粉 #FB7299 + 动漫柔和色系）+ 图渲染库（relation-graph / vue-flow / AntV X6 选一）做技能树；闯关/答题反馈动画自定义组件。
- 2026-08-22 Q18: **管理员 RAG 预建知识库**：管理员通过自建管理页面（Vue + Django API）上传文档、触发索引、查看进度/状态、发布/下线知识库；知识库成为产品内容层，就绪的知识库以主题卡片形式展示，用户点击直达启动 Journey。
- 2026-08-22 Q18a: **企业级 RAG 全流程**：解析 → 切分 → embedding → 索引 → 检索（混合检索 + query rewriting）→ **rerank 必配** → 生成（带引用）。所有企业级步骤都设计进项目。
- 2026-08-22 Q18b: 索引策略 = **全量重建**（知识库任何变更触发重建，分钟级可接受）。
- 2026-08-22 Q18c: **删除场景采用企业级软删除 + 检索过滤**（学习实现方式）：Django 文档记录软删标记，Milvus 向量 metadata 带有效标记、检索时 filter 排除；移除文档立即生效（无需等重建），重建时物理剔除。
- 2026-08-22 Q19: 主题关系 = **1 库 1 主题**（主题字段在知识库上：名称/描述/封面），主题列表页 = 就绪知识库卡片页，点击直达启动 Journey。
- 2026-08-22 Q19a: **RAG 两轮解构**：第一轮概览检索（文档结构/摘要片段）→ LLM 建图谱骨架（章节+知识点），第二轮按知识点检索细化前置依赖。解构/出题两个环节都吃检索。
- 2026-08-22 Q20 (默认项): 管理员 = Django `is_staff`（管理知识库）；普通用户 = 学习者/好友。知识库文档格式与输入形态一致（pdf/docx/pptx/md/txt/html），软删可恢复。多 Journey 并行无串行限制。
