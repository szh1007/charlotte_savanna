# 知识获取统一管道（材料也联网搜索增强）

初案是"主题模式 vs 材料模式"双模式（输入几句话 → 搜索；输入文档 → 只解析材料）。决定：统一管道 —— 输入归一化解析 → 主内容分析 → **联网搜索增强（即使已有材料也执行）** → 知识解构。网络搜索是标配增强环节而非可选项。

**Status**: accepted

**Considered Options**:
- 双模式分支：逻辑分裂，材料质量依赖单一来源
- 仅材料不出题外知识：知识面受限，材料过时则内容过时
- 统一管道（采纳）：材料往往不完整或过时，联网搜索补全知识面并交叉验证；单一管道减少分支逻辑，检索源可插拔（网络 / Context7 / 知识库 / 文档）

**Consequences**: 每次学习旅程都会产生网络搜索调用（成本/延迟），由任务系统异步化 + SSE 进度缓解。
