# 05 — 闯关答题与通关结算

**Status:** ready-for-agent

**Blocked by:** 04 — 技能树地图

**What to build:** 完整的闯关答题闭环：进入关卡（5-8 题，由浅入深、简单题收尾；选择 / 判断 / 填空三种题型交互，填空模糊匹配判分；本票题目先由 stub 生成器产出）→ 提交答案立即判分 → 展示预生成讲解（含来源引用位）→ 答错扣心动值（5 心，扣完重开）→ 温和鼓励动画（非红色错误界面）→ 通关结算（XP / 学习币发放、连胜更新、技能树节点点亮）。答题记录（Attempt）与用户事件逐条落库。

**Acceptance criteria:**
- [ ] 三种题型完整可答，填空模糊匹配（归一化）判分合理
- [ ] 答对答错均展示讲解，答错扣心动值，5 心扣完本关重开
- [ ] 答错展示温和鼓励动画，非错误红叉界面
- [ ] 通关结算：XP / 学习币 / 连胜与规则一致，节点点亮
- [ ] Attempt 与用户事件（答题/通关）逐条落库，可作为统计事实源
- [ ] 关卡由浅入深 + 简单题收尾的题目顺序策略生效

**Skills:** 前端部分开发时使用 `/frontend-design` 技能（视觉设计规范与主题落地）
