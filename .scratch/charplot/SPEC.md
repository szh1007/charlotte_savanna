# CharPlot 技术方案规格说明书

> 来源：2026-08-21/22 `/grill-with-docs` 审问会话产出。术语表见 [CONTEXT.md](../../project/charplot/docs/CONTEXT.md)，架构决策见 `project/charplot/docs/adr/0001 ~ 0003`。

## 1. 产品概述

**CharPlot** 是 AI 闯关学习网站：用户输入想学的任何知识（一句话 / 一段话 / 文档 / 网页链接），AI 自动联网获取知识、解构成知识图谱、渐进生成交互式问答闯关；通过 Duolingo 式游戏化机制（XP / 连胜 / 心动值）+ 技能树可视化 + 间隔复习，让用户更轻松地学习任意知识。

**定位**：自用学习项目，但架构按真实产品设计（账号体系 / 分享 / 部署齐全）。付费商业机制一律降级为轻量化实现（如连胜冻结卡 → 学习币兑换）。

## 2. 项目约定（用户指定）

1. 项目名称：**CharPlot**
2. Django 侧后端目录：`app/charplot`
3. FastAPI LLM/AI 侧后端目录：`project/charplot`（原 `project/breakthrough_study`）
4. 前端目录：`project/charplot/frontend`（Vue 3 + Vite）
5. Django 侧数据模型名称统一加前缀 **`charplot_`**（如 `charplot_journey`）
6. 用户数据主体使用 Django 自带 `auth_user`；专属用户字段按 **`charplot_profile`** 表存储（参考 `minimall_profile` 与 `auth_user` 的关联设计）

## 3. 核心概念

| 概念 | 定义 |
|------|------|
| **Journey（学习旅程）** | 一次输入（主题 / 材料 / 知识库）产出的完整学习单元：知识图谱 + 关卡集 |
| **Chapter（章节）** | 图谱第一层分组，末尾可挂 Boss 关（二期） |
| **KnowledgePoint（知识点）** | 原子节点，前置依赖边构成有向图；易错分锚点 |
| **Level（关卡）** | 挂知识点 + 序号（1:N），3 分钟量级，5-8 题 |
| **Question（题目）** | 选择 / 判断 / 填空；含讲解、来源引用 |
| **Attempt（答题记录）** | 逐题：所选答案、对错、时长、时间戳 |
| **KnowledgeBase（知识库）** | Milvus collection + Django 元数据；1 库 1 主题 |
| **ReviewReport（复盘报告）** | 通关总结，公开链接页可分享 |
| **Streak / XP / Heart / Coin** | 连胜 / 经验值等级 / 心动值（5 心）/ 学习币 |

## 4. 系统架构

**双后端微服务**（[ADR-0001](./adr/0001-dual-backend-microservices.md)）：

```
┌─────────────── Vue 3 前端 (project/charplot/frontend) ───────────────┐
│  Element Plus (B站粉动漫风) + 图渲染库(技能树) + 答题动画自定义组件       │
└──────┬──────────────────────────┬──────────────────────────┬─────────┘
       │ HTTP                     │ HTTP + SSE               │ HTTP
┌──────▼──────────────┐   ┌───────▼─────────────────────────┐ │
│ Django (app/charplot)│   │ FastAPI (project/charplot)      │ │
│ 账号体系 (auth_user) │   │ AI 能力端:                      │ │
│ 学习数据 (charplot_*)│◄──┤ 知识管道(解析→搜索→解构→出题)     │ │
│ 闯关交互(判分/游戏化) │   │ RAG 全链路(索引/检索/rerank/生成) │ │
│ 后台分析 Dashboard   │   │ Boss 战对话流式(二期)            │ │
│ 知识库元数据         │   │ 任务系统(异步+Redis+SSE)         │ │
│ 公开分享页           │   │ 语言: LangChain+LangGraph+DeepAgents │
└──────┬──────────────┘   └───────┬─────────────────────────┘ │
       │        共享 MySQL         │        共享 Milvus / Redis   │
       └───────────────────────────┴───────────────────────────┘
```

**职责切分原则**：Django = 状态与数据，FastAPI = AI 能力。首版闯关交互归 Django（纯规则 + 预生成讲解，无 LLM 参与，见 [ADR-0003](./adr/0003-level-interaction-in-django.md)）。

**技术栈**：

| 层 | 技术 |
|----|------|
| Django 侧 | Django 6.0 + DRF + MySQL + Redis |
| FastAPI 侧 | FastAPI + LangChain + LangGraph + DeepAgents + Milvus + Redis |
| 前端 | Vue 3 + Vite + TypeScript + Element Plus + 图渲染库（relation-graph / vue-flow / AntV X6 选一） |
| 异步编排 | FastAPI 异步任务 + Redis 任务状态 + SSE 进度推送，失败自动重试 |

## 6. 核心流程

### 6.1 管理员预建知识库（新需求）

```
管理员(is_staff) → 自建 RAG 管理页面 → 创建知识库(主题名/描述/封面)
  → 上传文档(pdf/docx/pptx/md/txt/html) → 触发索引 → FastAPI 任务
  → 解析 → 切分 → embedding → Milvus 入库 → 就绪 Ready
  → 主题卡片出现在用户端主题列表页
```

- 状态机：`草稿 Draft → 索引中 Indexing → 就绪 Ready`，失败 Failed 可重试，可手动下线
- 索引策略：**全量重建**（任何变更触发重建，分钟级可接受）
- 删除：**软删除 + 检索过滤**——Django 文档记录 `is_deleted` 标记 + Milvus 向量 metadata 有效标记，检索时 filter 排除；移除立即生效，重建时物理剔除；软删可恢复
- **企业级 RAG 全流程**（必配）：解析 → 切分 → embedding → 索引 → **混合检索（稠密 + 稀疏）+ query rewriting → rerank** → 生成（带引用）

### 6.2 用户开启学习旅程

```
用户 → 输入材料/主题 或 点击主题卡片(知识库)
  → FastAPI 异步任务(SSE 进度) → 统一知识管道:
      ① 归一化解析(文档/链接) 或 知识库 RAG 两轮解构
      ② 主内容分析
      ③ 联网搜索增强
      ④ 图谱解构(章节 → 知识点 + 依赖边) → 技能树全貌可见
  → 用户进入闯关地图 → 点击关卡 → 渐进生成题目(预生成下一关)
  → 闯关答题 → 通关 → 点亮技能树节点 → 下一关
```

**知识库解构（RAG 两轮）**：第一轮概览检索（文档结构/摘要片段）→ LLM 建图谱骨架；第二轮按知识点检索细化前置依赖。

### 6.3 闯关答题

```
进入关卡(5-8 题, 由浅入深, 简单题收尾) → 答题(选择/判断/填空)
  → 立即判分(规则) + 展示讲解(预生成, 含来源引用)
  → 答错扣心动值(5 心扣完需重开) → 通关 → XP/学习币发放 + 连胜更新
  → 新关生成时: 易错分 × 时间衰减排序混入 Top 20% 历史易错知识点
```

## 7. 知识管道详细设计

### 7.1 统一管道（[ADR-0002](./adr/0002-unified-knowledge-pipeline.md)）

```
输入(文本/文档/链接/知识库) → 归一化解析 → 主内容分析 → 联网搜索增强 → 知识解构 → 渐进出题
```

- 输入几句话 → 联网搜索获取知识
- 输入材料 → 先解析分析材料，**再联网搜索增强**（补全知识面 + 交叉验证）
- 检索源可插拔：网络搜索 / Context7 / 知识库 / 文档

### 7.2 RAG 架构（FastAPI 全链路）

| 环节 | 实现要点 |
|------|---------|
| 解析 | 多格式（pdf/docx/pptx/md/txt/html），复用 deep_search 解析工具经验 |
| 切分 | chunk_size / chunk_overlap 按文档类型调优，metadata 保留（来源/文档 id/有效标记） |
| Embedding | 模型接入抽象，可切换 |
| 索引 | Milvus collection + 稀疏索引（混合检索用），软删除标记写入 metadata |
| 检索 | **混合检索（稠密向量 + BM25 稀疏融合）** + query rewriting，Top-K 召回 |
| Rerank | **必配**，精排后取 Top-K 进 prompt |
| 生成 | 题目/讲解**只基于检索片段生成**（生成约束），附来源引用（[Q8 幻觉防护]） |

### 7.3 幻觉防护（三层）

1. 生成约束：题目/讲解只基于检索片段，不允许自由发挥
2. 来源展示：讲解区附来源链接
3. 反馈标记：「题目有问题」标记计入后台分析

## 8. 数据模型（Django 侧，前缀 `charplot_`）

```
charplot_profile (1:1 → auth_user)      # 用户扩展：游戏化状态等
charplot_knowledge_base                 # 知识库：主题字段(名称/描述/封面)、状态机、Milvus collection 配置
charplot_knowledge_base_document        # 知识库文档：文件记录、is_deleted 软删标记
charplot_journey                        # 学习旅程：输入快照、来源类型(材料/主题/知识库)、图谱
charplot_chapter                        # 章节
charplot_knowledge_point                # 知识点：前置依赖边(自引用 M2M)、易错分
charplot_level                          # 关卡：FK 知识点 + 序号(1:N)、题型配置
charplot_question                       # 题目：类型(选择/判断/填空)、选项、答案、讲解、来源引用
charplot_attempt                        # 答题记录：逐题事实(所选答案/对错/时长/时间戳)
charplot_review_report                  # 复盘报告：公开 slug、OG 信息
charplot_user_event                     # 用户事件(登录/通关/答题等) → 事实静态记录统计源
```

- 用户统计面板（登录天数 / 连胜 / 最大连胜 / 已学章节 / 在学章节 / 已答/答对/答错数）：事实表全记录，聚合按需计算
- 游戏化状态（XP / 等级 / 连胜 / 心动值 / 学习币）挂 `charplot_profile`

## 9. 游戏化设计（Duolingo 参考）

| 机制 | 设计 |
|------|------|
| 轻量微学习 | 3 分钟/关，5-8 题 |
| 渐进认知阶梯 | 单关由浅入深（识别 → 回忆），简单题收尾保成功感 |
| XP + 等级 | 答题/通关累积 |
| 连胜 Streak | 连续学习天数，习惯钩子 |
| 心动值 Heart | 5 心，答错扣心，扣完重开——「安全失败」体验，答错展示温和鼓励动画（非红色错误界面） |
| 学习币 Coin | 通关获得，兑换连胜冻结等轻量化付费替代 |
| 技能树 | 图谱节点点亮动画，具象化成长反馈 |
| 间隔复习 | 易错分（答错+2/答对-1，下限 0）× 时间衰减，新关混入 Top 20%；无独立复习页 |

## 10. 后台分析（自建 Dashboard，Vue + Django API）

1. **掌握度矩阵**：按知识点/章节正确率，薄弱点高亮
2. **学习活动统计**：时长 / 通关数 / 活跃天数 / 连胜
3. **易错点清单**：易错分排序 + 复习优先级（与间隔复习同源）
4. **LLM 文字版状态总结**：统计聚合结果 → FastAPI 接口 → LLM 生成文字总结（强项/弱项/建议）

事实静态记录（全埋点）：登录天数、连胜/最大连胜、已学章节、在学章节、已答题数、答对数、答错数等。

## 11. 分享与报告
