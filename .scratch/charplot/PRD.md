# CharPlot 产品需求文档（PRD）

## 1. 产品概述

**CharPlot** —— AI 闯关学习网站。用户输入想学的任何知识（一句话 / 一段话 / 文档 / 网页链接），AI 自动获取知识、解构成技能树图谱、渐进生成问答闯关；以 Duolingo 式游戏化机制让学习像打游戏一样轻松上瘾，通关后生成可分享的复盘报告。

**价值主张**：更快、更轻松地学习任何知识 ——
- **低门槛启动**：一句话就能开学（如"我想学 Python 装饰器"）
- **游戏化驱动**：闯关 / 连胜 / 技能树点亮，把数月学习的延迟满足拆解为即时正向激励
- **无痛巩固**：间隔复习混入历史易错点，对抗遗忘曲线
- **有据可依**：每题附来源引用，学错有反馈通道

**定位**：个人学习项目，产品与架构按真实产品设计（账号 / 分享 / 部署齐全）；付费商业机制不引入，以轻量化策略替代。

## 2. 目标用户与场景

| 角色 | 描述 | 核心场景 |
|------|------|---------|
| 学习者（本人 / 好友） | 想学任何知识的用户 | 输入主题或点击主题卡片 → 闯关学习 → 复盘 |
| 管理员（本人，`is_staff`） | 内容配置者 | 预建主题知识库 → 用户点击直达开课 |

**典型场景**：
1. 今天想学"Python 装饰器"，输入一句话 → 3 分钟后开始第一关
2. 手头有一份《Django 教程》PDF，上传 → AI 联网补充最新知识 → 生成技能树地图
3. 管理员预建"RAG 实战"知识库（上传笔记+官方文档）→ 主题卡片上线 → 直接点击开课
4. 连续 7 天通关后，复盘报告分享到朋友圈

## 3. 核心用户故事

- 作为学习者，我输入一句话或上传材料，AI 能自动获取知识并生成闯关地图，**无需我整理内容**
- 作为学习者，我能在技能树上看到全部知识节点与依赖关系，通关节点被点亮，**获得具象的成长反馈**
- 作为学习者，我答题后立刻看到对错与讲解（答错也有讲解+来源），**错也错得明白**
- 作为学习者，我在后续关卡中无感遇到之前答错的 20% 知识点，**对抗遗忘**
- 作为学习者，我通关整个旅程后得到复盘报告，并可分享给好友
- 作为管理员，我能通过 RAG 界面预建主题知识库，配置完成后用户在主题页一键开课

## 4. 功能需求

> 优先级：P0 = 首版核心闭环 ｜ P1 = 首版完整 ｜ P2 = 二期

### A. 账号与个人（P0）

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| A-1 | 注册 / 登录（用户名密码，Django 内置认证） | 未登录可浏览主题列表；登录后可开旅程 |
| A-2 | 个人主页展示：等级 / XP / 连胜 / 最大连胜 / 心动值 / 学习币 | 数据与答题行为实时同步 |
| A-3 | 用户事件全埋点：登录天数、已学/在学章节、已答/答对/答错数 | 统计面板数字与 Attempt 事实表一致 |

### B. 知识输入与旅程创建（P0）

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| B-1 | 输入形态：一句话 / 一段话 / 文档（pdf/docx/pptx/md/txt/html）/ 网页链接 | 各形态均可成功创建旅程 |
| B-2 | 生成进度展示：阶段化 SSE（解析 → 分析 → 搜索 → 解构 → 完成） | 前端可见当前阶段与进度，失败可重试 |
| B-3 | 旅程列表：进行中 / 已通关 | 可随时回到未完成的旅程继续 |

### C. 知识库（管理员预建，P1）

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| C-1 | 管理员创建知识库：主题名 / 描述 / 封面图 | 仅 `is_staff` 可操作 |
| C-2 | 文档管理：上传 / 列表 / 移除（软删除，可恢复） | 移除后检索立即不命中该文档 |
| C-3 | 索引任务：触发 → 进度展示（解析/切分/embedding/入库）→ 完成 | 状态机：草稿 → 索引中 → 就绪 / 失败可重试 |
| C-4 | 主题卡片页（用户端）：就绪知识库以卡片展示，点击直达开 Journey | 仅就绪状态展示；下线后不可见 |

### D. 闯关答题（P0）

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| D-1 | 技能树地图：图谱可视化（节点 + 依赖边），通关点亮动画 | 大知识点拆多关时节点进度合并显示 |
| D-2 | 关卡体验：5-8 题，由浅入深，简单题收尾（3 分钟量级） | 认知阶梯：识别 → 回忆 |
| D-3 | 题目类型：选择 / 判断 / 填空 | 填空模糊匹配判分合理 |
| D-4 | 即时反馈：答对答错均展示讲解 + 来源引用；答错扣心动值（5 心） | 温和动画鼓励，非红色错误界面；心扣完需重开本关 |
| D-5 | 通关结算：XP / 学习币发放、连胜更新、节点点亮 | 数字与游戏化规则一致 |
| D-6 | 间隔复习：新关生成时按「易错分 × 时间衰减」混入 Top 20% 历史易错知识点 | 复习题无感融入，不标记"复习"字样 |
| D-7 | 「题目有问题」反馈标记 | 标记计入后台分析 |

### E. 复盘报告与分享（P0 基础 / P1 完整）

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| E-1 | 通关生成复盘报告：知识总结 + 答题表现 | 旅程通关后生成 |
| E-2 | 公开分享链接（slug URL）+ OG 社交卡片，无登录可看 | 分享页只读；未登录可访问 |

### F. 后台分析 Dashboard（P1）

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| F-1 | 掌握度矩阵：按知识点/章节正确率，薄弱点高亮 | 数据与 Attempt 一致 |
| F-2 | 学习活动统计：时长 / 通关数 / 活跃天数 / 连胜趋势 | 图表展示 |
| F-3 | 易错点清单 + 复习优先级（与间隔复习同源） | 按易错分排序 |
| F-4 | LLM 文字版状态总结：强项 / 弱项 / 建议 | 点击生成，FastAPI 出接口 |

### G. 游戏化系统（P0 = G1-G3 / P1 = G4）

| 编号 | 需求 | 说明 |
|------|------|------|
| G-1 | XP + 等级 | 答题/通关累积，等级成长反馈 |
| G-2 | 连胜 Streak | 连续学习天数，习惯钩子；中断后显示损失警告 |
| G-3 | 心动值 Heart | 5 心，答错扣心，安全失败机制 |
| G-4 | 学习币 Coin | 通关获得，兑换「连胜冻结」（轻量化替代付费） |
| G-5 | Boss 关 | 首版：章节末尾高难度标记关（混合题型）；二期：对话式 AI 角色扮演 |

## 5. 非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 闯关判分即时（<500ms）；生成任务异步化，SSE 进度反馈；预生成下一关掩盖 LLM 延迟 |
| 正确性 | 题目/讲解只基于检索片段生成；每题附来源引用；「题目有问题」反馈通道 |
| 安全 | 敏感配置走 .env；分享页只读防篡改；管理员操作限 `is_staff` |
| 成本 | 题目按需生成（学到哪生成到哪）；间隔复习复用已生成讲解 |
| 数据 | 事实记录全埋点（Attempt + 用户事件）；知识库软删除可恢复 |

## 6. 视觉与体验方向

- **配色**：B 站粉 `#FB7299` 主色 + 二次元柔和色系（奶白 / 浅紫 / 淡蓝），圆角卡片、软阴影
- **氛围**：动漫风、轻松、柔和——答错是温和的鼓励动画，不是冰冷的红叉
- **组件**：Element Plus 主题定制 + 自定义答题/闯关动画 + 技能树图渲染（点亮动画）
- **动效**：进度条增长、节点点亮、结算彩花（Duolingo 式即时正向激励）

## 7. 范围与里程碑

### 首版（P0 + P1）

**阶段 1 —— 核心闭环**：账号（A）→ 输入创建旅程（B）→ 闯关答题（D1-D5）→ 通关结算（G1-G3）→ 复盘报告（E1）

**阶段 2 —— 完整功能**：管理员知识库（C 全）→ 间隔复习（D6）→ 题目反馈（D7）→ 分析 Dashboard（F）

### 二期（P2）

视频输入（复用 video_downloader 转录）、代码题、对话式 Boss 战、成就勋章、排行榜、增量索引

## 8. 成功指标（自用学习场景）

| 指标 | 目标 |
|------|------|
| 学习有效性 | 闯关正确率 ≥ 70%；掌握度随时间提升（分析 Dashboard 可查） |
| 习惯养成 | 周活跃 ≥ 5 天；连胜中断频率低 |
| 完成度 | 已启动 Journey 通关率 ≥ 50% |
| 内容质量 | 「题目有问题」标记率 < 2% |
