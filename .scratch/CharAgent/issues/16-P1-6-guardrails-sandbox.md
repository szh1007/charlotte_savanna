# 16-P1-6 — 安全护栏 + 工具沙箱 + SSRF（四层纵深）

> **2026-09-18 修订**（ADR-0008/0009）：**工具沙箱的形态改变**。原设计是「agent 直连 MySQL + 只读账号 + SQL 白名单」；改走网关后，agent 侧不再持有业务系统地址与凭证，沙箱职责分散到三层——**agent 侧**（出站目标白名单 + 参数校验）、**网关侧**（验签 + 参数校验 + 限流）、**业务系统侧**（internal 端点自身的参数校验 + 只读账号）。#24 难点仍被覆盖，只是落点不同。

**What to build:** 四层纵深护栏：输入护栏（Prompt Injection 防护 #23）、工具护栏（沙箱/最小权限：**出站目标白名单**（工具只能访问配置的网关地址，不能任意 URL）+ 参数校验防注入与路径穿越 #24；业务数据侧的最小权限由业务系统 internal 端点 + 只读账号承担）、输出护栏（引用溯源 #29 + 内容过滤）、数据访问护栏（SSRF 防护 #30：外部 URL 访问白名单/内网地址拦截）。护栏拦截有指标（guardrail block rate）供监控。

**Blocked by:** 11, 12
