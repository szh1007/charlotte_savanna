**What to build:** 免费档与会员档存在真实功能差异并由后端强制：免费用户仅能使用 ≤720p 档位（更高档位标记锁定且选择被拒）；会员解锁全部清晰度、3 个并发槽、队列上限 50、调度优先。

**Blocked by:** 02 — 下载 + 交付直链链路, 04 — 会员鉴权

**Status:** resolved

**验收标准：**
- [x] 免费用户解析结果中 >720p 档位标记 `locked`（如 1080p / 4K / 最佳画质）
- [x] 免费用户选择 locked 档位 → 后端拒绝并提示需会员

- [x] 会员用户可解析并下载全部档位

- [x] 会员任务优先于免费任务分配并发槽
- [x] pytest 全部通过（免费 / 会员差异矩阵：档位锁定、并发数、队列 429、优先调度）
