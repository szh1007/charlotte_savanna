# 05 — 付费差异（后端强制）

**What to build:** 免费档与会员档存在真实功能差异并由后端强制：免费用户仅能使用 ≤720p 档位（更高档位标记锁定且选择被拒）；会员解锁全部清晰度、3 个并发槽、队列上限 50、调度优先。

**Blocked by:** 02 — 下载 + 交付直链链路, 04 — 会员鉴权

**Status:** ready-for-agent

**验收标准：**
- [ ] 免费用户解析结果中 >720p 档位标记 `locked`（如 1080p / 4K / 最佳画质）
- [ ] 免费用户选择 locked 档位 → 后端拒绝并提示需会员
- [ ] 下载执行前对非会员任务重新校验所选档位清晰度，直接绕过尝试（伪造请求）被拒绝
- [ ] 会员用户可解析并下载全部档位
- [ ] 并发差异：免费档 1 并发槽 / 会员档 3 并发槽
- [ ] 队列差异：免费档上限 5（超限返回 429 + 明确提示）/ 会员档上限 50
- [ ] 会员任务优先于免费任务分配并发槽
- [ ] pytest 全部通过（免费 / 会员差异矩阵：档位锁定、并发数、队列 429、优先调度）
