# 07 — 前端工程 + 主题 + Hero 解析区

**What to build:** 用户打开首页即看到一个独特精致的深色粉紫渐变主题界面（参考 ai.codefather.cn/painting 风格，营销导向）；在 Hero 区粘贴视频链接即可发起解析，并看到解析结果（标题 / 封面 / 时长 / 清晰度列表）。

**Blocked by:** 01 — 后端骨架 + 解析链路

**Status:** ready-for-agent

**验收标准：**
- [ ] Vite + Vue 3 独立工程可 `npm run dev` 启动（独立开发，不参考本仓库其他 demo/子项目）
- [ ] 设计令牌系统生效（theme.css）：主色 `#eb2f96`、粉紫渐变 `linear-gradient(135deg, #eb2f96, #722ed1)`、深紫黑背景 `#0d0a1a`、16px 圆角
- [ ] 导航栏：Logo + 会员入口（渐变描边按钮）
- [ ] Hero 区：大标题「全网视频，一键下载」+ 副标题 + 大号链接输入框 + 粉紫渐变解析按钮 + 平台标签云
- [ ] 粘贴链接 → 点击解析 → 调用解析接口 → 展示解析结果（标题 / 封面 / 时长 / 清晰度列表）
- [ ] 解析中加载态、解析失败错误提示
- [ ] 响应式布局（手机浏览器可用）
- [ ] 浏览器验收通过（与真实后端联调）
