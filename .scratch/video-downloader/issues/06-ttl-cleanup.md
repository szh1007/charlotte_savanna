# 06 — TTL 清理 + 直链过期

**What to build:** 交付文件不是永久资产：后台任务周期性扫描，将超过有效期的已完成任务标记为过期并删除其文件；过期任务的直链返回明确过期响应；免费档有效期 24h，会员档 72h。

**Blocked by:** 02 — 下载 + 交付直链链路, 04 — 会员鉴权

**Status:** ready-for-agent

**验收标准：**
- [ ] 后台清理周期性执行（约 60s 周期）
- [ ] completed 任务超过 TTL → 文件被删除 + 任务标记 expired
- [ ] TTL 按身份区分：免费任务 24h / 会员任务 72h
- [ ] expired 任务的直链请求返回 404/410 与明确提示（文件已清理）
- [ ] 清理逻辑不误伤未过期任务，重复清理幂等
- [ ] 时间判定使用可注入时钟（测试可推进时间）
- [ ] pytest 全部通过（推进时钟断言文件删除、状态标记、过期响应）
