# 08 — 前端解析结果卡 + 任务面板

**What to build:** 用户在解析结果卡中选择清晰度档位发起下载（免费档锁定档位带 🔒 标识），创建的任务出现在任务面板并实时显示进度（SSE 推送，无需刷新）；完成后可一键下载文件或复制交付直链。

**Blocked by:** 02 — 下载 + 交付直链链路, 07 — 前端工程 + 主题 + Hero 解析区

**Status:** ready-for-agent

**验收标准：**
- [ ] 解析结果卡：封面 + 标题 + 平台徽章 + 时长 + 清晰度下拉（免费锁定档位带 🔒 标识）→「开始下载」按钮
- [ ] 点击开始下载 → 创建下载任务 → 任务出现在任务面板
- [ ] 任务卡片：封面缩略图 + 进度条 + 状态徽章（排队中 / 下载中 / 已完成 / 失败 / 已过期）+ 失败原因展示
- [ ] 通过 SSE 实时更新进度与状态（无刷新、无轮询）
- [ ] 完成后显示「下载到手机/电脑」按钮（打开交付直链）+ 「复制链接」按钮
- [ ] 页面恢复初始状态后任务列表可从接口恢复（GET /api/tasks）
- [ ] 浏览器端到端通过（真实后端：解析 → 下载 → 实时进度 → 直链下载）
